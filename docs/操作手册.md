# MSU2 小屏幕 · iStoreOS 操作手册

> 适用：iStoreOS 软路由（192.168.10.1，Radxa E20C / aarch64）+ MSU2 USB 小屏（CH32x035，160×80）
> 部署目录：`/mnt/mmc1-4/msu2d`
> 仓库根目录：`forIstoreOS/`（可整体上传 Git）
> 最后更新：2026-09-14

---

## 1. 一分钟上手

```bash
# 登录软路由（SSH 或 LuCI 终端）
ssh root@192.168.10.1

# 进入项目
cd /mnt/mmc1-4/msu2d/src

# 三页轮播（网速 / 系统 / 时间+客户端），每页 15 秒
python3 -m msu2.main --page auto --rotate 15

# 只显示某一页
python3 -m msu2.main --page net      # 网速
python3 -m msu2.main --page sys      # CPU/温度/内存
python3 -m msu2.main --page clock    # 时间+客户端

# 定时运行（跑 N 帧后自动退出，便于测试）
python3 -m msu2.main --frames 60 --interval 1

# Ctrl+C 退出（退出后设备回到待机态，屏幕保留最后一帧画面）
```

参数说明：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--page` | auto | auto / net / sys / clock |
| `--interval` | 1.0 | 刷新间隔（秒） |
| `--rotate` | 15.0 | auto 模式每页停留秒数 |
| `--frames` | 0 | 最多刷新 N 帧后退出（0=一直跑） |
| `--once` | - | 只刷一帧 |
| `--quiet` | - | 少打日志 |
| `--device` | 自动 | 指定串口设备（默认按 VID:PID 1a86:fe0c 自动查找） |

## 2. 网页控制（LuCI 模块，推荐日常使用）

打开：**http://192.168.10.1/cgi-bin/luci/admin/services/msu2**
（菜单路径：**服务 → USB副屏 (MSU2)**）

可设置项：

| 项目 | 说明 |
| --- | --- |
| **启用屏幕显示** | 开=接管屏幕；关=停止出帧，屏幕回到固件自带动画 |
| **显示页面** | 自动轮播 / 仅网速 / 仅系统状态 / 仅时间+客户端 |
| **刷新间隔（秒）** | 建议 1 秒 |
| **轮播每页停留（秒）** | 仅"自动轮播"时生效，默认 15 秒 |
| **屏幕方向** | 正向(0°) / 反向(180°) / 水平镜像 / 垂直镜像 / 顺时针90° / 逆时针90° / 镜像+90° |
| **立即重启显示进程** | 手动重启按钮 |

页面下方还会显示**运行状态**（设备是否识别、进程是否在跑、当前页面/刷新/方向）和**最近日志**。
点击"保存&应用"后服务会自动重启，配置立即生效。

### 2.1 命令行等价操作（网页打不开时用）

```bash
uci set msu2.settings.enabled=1        # 0=关闭显示
uci set msu2.settings.page=auto        # auto / net / sys / clock
uci set msu2.settings.interval=1       # 刷新间隔（秒）
uci set msu2.settings.rotate=15        # 轮播停留（秒）
uci set msu2.settings.direction=0      # 屏幕方向 0..7
uci commit msu2
/etc/init.d/msu2d restart
```

### 2.2 服务管理

```bash
/etc/init.d/msu2d start | stop | restart    # 启动/停止/重启显示
/etc/init.d/msu2d enable                    # 设为开机自启（默认未开启）
/etc/init.d/msu2d disable                   # 取消开机自启
logread -e msu2d                            # 查看服务日志
```

### 2.3 重新安装/修复 LuCI 模块

从备份还原、或系统升级后丢失菜单时执行：

```bash
sh /mnt/mmc1-4/msu2d/tools/install_luci.sh
```

该脚本幂等，重复执行安全（会安装 UCI 配置、init 服务、Lua 控制器与设置页，并重启服务）。

## 4. 页面说明

| 页面 | 内容 |
| --- | --- |
| **net 网速** | 顶部：WAN 协商速率（如 `1.0G FULL`）／中部：<下载图标> + 大号下行速度／下部：<上传图标> + 大号上行速度／底部：WAN 口当前 IP（运营商大内网时右侧标 `NAT`）。**无曲线图** |

## 5. 常用命令速查

```bash
# 看设备是否在（USB）
lsusb | grep -i ch32
ls -l /dev/ttyACM0

# 看设备是否待机（应有 10Hz 心跳数据）
cat /dev/ttyACM0 | hexdump -C        # Ctrl+C 退出

# 看系统指标
cat /sys/class/thermal/thermal_zone0/temp        # CPU 温度（毫摄氏度）
cat /sys/class/net/pppoe-wan/statistics/rx_bytes # WAN 收字节
free -m                                          # 内存

# 看在线客户端（ARP 活跃设备）
cat /proc/net/arp

# 用 Python 看客户端明细
cd /mnt/mmc1-4/msu2d/src
python3 -c "import sys; sys.path.insert(0,'.'); from msu2.metrics import Metrics; print(Metrics().client_list())"

# 生成页面预览图（4 倍放大 PNG）
cd /mnt/mmc1-4/msu2d
python3 tools/preview.py --out /tmp/preview --scale 4
ls -l /tmp/preview/
```

## 6. 常见故障处理

### 6.1 屏幕不亮 / 不刷新

1. 确认设备在：`lsusb | grep -i ch32` 应显示 `1a86:fe0c CH32x035`
2. 确认串口存在：`ls -l /dev/ttyACM0`
3. 看是否待机：`cat /dev/ttyACM0 | hexdump -C`（有 10Hz 心跳 = 正常待机）
4. 重新运行程序：`cd /mnt/mmc1-4/msu2d/src && python3 -m msu2.main --page auto`

### 6.2 程序报"写入超时 / 设备可能已卡死"

**这是屏幕固件卡死**（MCU 主循环停了，但 USB 还枚举）。判定特征：写入队列排空不了。

**唯一有效的恢复办法：拔掉屏幕 USB 线，等 10 秒，再插回去。**

> 注意：`echo 0/1 > /sys/bus/usb/devices/3-1/authorized` 之类的 USB 软复位**无效**，
> 因为卡的 MCU 主循环不会被 USB 复位重置。

**预防**（程序已实现，改代码时务必保留）：
- `LCD_ADD`（设置显示区域）**只在进入页面时发一次**，连续刷新时绝不再发
- 每帧数据必须**完整写出**，不能中途中断
- 帧数据中途**不要插入**其它命令（读寄存器 / 读按键 / 切方向）

### 6.3 屏幕显示时间不对

路由器时区已由系统配置（`CST-8` / Asia/Shanghai），`time.localtime()` 就是北京时间。
**不要再手动加时区偏移**（本项目曾因此显示成晚上 9 点）。

检查：`date` 应显示正确时间；不对则 `uci set system.@system[0].timezone='CST-8'` 或改 LuCI 时区设置。

### 6.4 找不到串口设备（ttyACM0 变了）

程序会按 `VID:PID = 1a86:fe0c` 自动扫描 `/dev/ttyACM*`、`/dev/ttyUSB*`；
也可以手动指定：`--device /dev/ttyACM1`。

## 7. 从备份还原（设备崩溃 / 重装系统后）

```bash
# 1) 把备份包上传到软路由（例如 /tmp）
#    本地 → 路由：可用 scp / LuCI 文件管理器上传

# 2) 解包还原（假设包名 msu2d-backup-20260912.tar.gz）
cd /mnt/mmc1-4
tar xzf /tmp/msu2d-backup-20260912.tar.gz     # 会还原出 msu2d/ 目录

# 3) 验证
cd /mnt/mmc1-4/msu2d/src
python3 -m compileall -q msu2 && echo 编译通过
python3 -m msu2.main --page clock --frames 5   # 试跑 5 帧
```

还原后如果屏幕没反应，按 6.2 拔插一次 USB 即可。

## 8. 修改页面布局的方法

1. 编辑 `/mnt/mmc1-4/msu2d/src/msu2/pages.py`
2. 生成预览图确认：
   ```bash
   cd /mnt/mmc1-4/msu2d && python3 tools/preview.py --out /tmp/preview --scale 4
   ```
   然后用 LuCI 文件管理器下载 `/tmp/preview/*.png` 查看
3. 预览满意后再刷到屏幕：
   ```bash
   cd /mnt/mmc1-4/msu2d/src && python3 -m msu2.main --page sys --frames 5
   ```

> 常用绘图 API（`canvas.py`）：
> `cv.text(x, y, "文字", 颜色, scale)` / `cv.bar(x, y, w, h, 比例, 颜色)` /
> `cv.rect(x, y, w, h, 颜色)` / `cv.graph(x, y, w, h, 数据, 最大值, 颜色)`

## 9. 协议速查（改代码时对照）

| 操作 | 字节包 |
| --- | --- |
| 握手 | `00 4D 53 4E 43 4E`（NUL + "MSNCN"）→ 设备回显一致 |
| 设置区域（**只发一次**） | `02 00 xH xL yH yL` + `02 01 wH wL hH hL` + `02 03 07 00 00 00` |
| 帧底色（每页） | `02 04` + 4 字节（大端，打包两个相邻像素） |
| 帧差异像素 | `04 <k>` + 4 字节 |
| 提交本页 | `02 03 08 01 00 00` |
| 读 SFR 寄存器 | `00 30 00 <addrH> <addrL> 00` → 回显末字节为值 |
| 读 ADC 按键 | `08 09 00 00 00 00`（仅待机态有效） |
| 设置方向 | `02 03 0A <dir> 00 00` |

设备状态：

- **待机态**：10Hz 发心跳，所有指令都回显
- **显示态**：心跳停止、指令不回显（**正常现象**）；只能靠"写入是否被消费"判断存活

## 10. 关键实测数据（性能预算参考）

| 项目 | 数值 |
| --- | --- |
| 屏幕分辨率 | 160×80（设备寄存器 `Lcd_X`=160 / `Lcd_Y`=80） |
| 单帧耗时 | 0.10–0.13 秒 |
| 单帧数据量 | 纯色约 1.2 KB；常规页面约 5–9 KB |
| 连续刷新 | 已验证 1Hz × 180 帧无异常；理论上限约 8 fps |
| USB | 全速（Full-Speed），设备取电约 140 mA |

## 11. 一键安装包（分发给同设备的其他人）

仓库位置：`dist/`（源码更新后应重新打包）

| 文件 | 大小 | 用途 |
| --- | --- | --- |
| `msu2d-install-1.0.sh` | 约 50 KB | **单文件自解压安装包**（推荐分发，一个文件搞定） |
| `msu2d-1.0.tar.gz` | 约 50 KB | 纯压缩包（需手动解包后执行 `tools/install.sh`） |

### 11.1 别人怎么装（一条命令）

```sh
# 把 msu2d-install-1.0.sh 传到对方路由器（scp / LuCI 文件管理器 / 网盘都行），然后：
sh /tmp/msu2d-install-1.0.sh
```

安装脚本会自动完成：

1. 检查并（尝试）安装 `python3-light`；
2. 复制程序到 `/mnt/mmc1-4/msu2d`（该路径不可用时回退 `/opt/msu2d`）；
3. 写入 `/etc/config/msu2`（**已存在则保留原配置**）；
4. 生成并安装服务 `/etc/init.d/msu2d`（路径按实际安装目录自动适配）；
5. 安装 LuCI 页面（服务 → USB副屏）；
6. 启动服务并自检（模块导入 / 进程状态），最后打印网页地址。

可选：装完想开机自启，执行 `/etc/init.d/msu2d enable`。

### 11.2 卸载

```sh
sh /mnt/mmc1-4/msu2d/tools/uninstall.sh
# 彻底删除： rm -rf /mnt/mmc1-4/msu2d /etc/config/msu2
```

### 11.3 安装包制作方法（自己更新后重新打包）

在仓库根目录执行：

```sh
sh tools/package.sh 1.0
```

脚本会先在 `/tmp` 中整理出顶层 `msu2d/` 目录，再生成：

- `dist/msu2d-1.0.tar.gz`
- `dist/msu2d-install-1.0.sh`

打包时会排除 `__pycache__/` 和 `*.pyc`。可用下面的命令先在临时目录测试，不覆盖正式发布包：

```sh
DIST=/tmp/msu2d-dist sh tools/package.sh 1.0-test
```

### 11.4 关于"正规 .apk 安装包"

本机 `apk-tools 3.0.5` **没有 `mkpkg` 子命令**，设备上也没有 gcc/make，所以**无法在设备上直接制作 .apk**。
若要发布成正规软件包（可在 LuCI「系统→软件包」里上传安装、可升级/卸载），需要用 **OpenWrt SDK** 在 Linux 上编译
（目标：`rockchip/armv8`、`aarch64_generic`；本包为纯 Python/Lua，可用 `PKGARCH:=all`）。
需要的话可以后续再做。
