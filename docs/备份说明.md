| 内容 | 位置 | 用途 |

## 3. 从完整备份还原

### 3.1 上传并解包

```sh
scp dist/msu2d-backup-20260912.tar.gz root@192.168.10.1:/tmp/
ssh root@192.168.10.1 "cd /mnt/mmc1-4 && tar xzf /tmp/msu2d-backup-20260912.tar.gz"
```

### 3.2 安装服务与 LuCI

```sh
ssh root@192.168.10.1 "sh /mnt/mmc1-4/msu2d/tools/install.sh"
```

### 3.3 验证

```sh
ssh root@192.168.10.1 "cd /mnt/mmc1-4/msu2d/src && python3 -m compileall -q msu2 && /etc/init.d/msu2d restart && sleep 3 && ps | grep -c '[m]su2.main'"
```

网页入口：

```text
http://192.168.10.1/cgi-bin/luci/admin/services/msu2
```

若屏幕没有反应，先确认进程和串口，再按操作手册执行一次物理拔插 USB。

## 4. 从路由器生成新备份

在路由器上执行：

```sh
cd /mnt/mmc1-4
tar czf /tmp/msu2d-backup-$(date +%Y%m%d).tar.gz \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  --exclude='var' \
  msu2d
cd /tmp
md5sum msu2d-backup-*.tar.gz > msu2d-backup-$(date +%Y%m%d).tar.gz.md5
```

然后把 `msu2d-backup-*.tar.gz` 和 `.md5` 拉回本地 `dist/`。

## 5. 重新生成发布包

确认源码修改并完成预览/语法验证后，在仓库根目录执行：

```sh
sh tools/package.sh 1.0
```

该命令会重新生成 `dist/msu2d-1.0.tar.gz` 和 `dist/msu2d-install-1.0.sh`。如果只是测试打包流程，可指定临时输出目录，避免覆盖正式发布包：

```sh
DIST=/tmp/msu2d-dist sh tools/package.sh 1.0-test
```

## 6. 分发给同设备的其他人

前提：目标设备为 MSU2/CH32x035（VID:PID `1a86:fe0c`），系统有 Python 3；需要网页控制时还要有 LuCI Lua 运行时。

```sh
# 对方路由器上执行
sh /tmp/msu2d-install-1.0.sh
```

安装后可选开机自启：

```sh
/etc/init.d/msu2d enable
```

卸载服务与 LuCI 页面：

```sh
sh /mnt/mmc1-4/msu2d/tools/uninstall.sh
```

配置文件 `/etc/config/msu2` 和程序目录默认保留，避免误删用户数据。

## 7. 把本目录上传到 Git

本目录已经按“仓库根目录”整理，包含 `README.md`、`.gitignore`、`.gitattributes` 和源码/文档/发布包。示例：

```bash
cd forIstoreOS
git init -b main
git add .
git commit -m "feat: MSU2 iStoreOS 1.0 可发布版本"
git remote add origin <你的 Git 仓库地址>
git push -u origin main
```

注意：

1. `dist/**` 被标记为二进制，Git 不会改动自解压安装包内部数据；
2. `__pycache__/`、`*.pyc`、`var/`、日志和本地编辑器目录不会提交；
3. 如果使用 GitHub 网页上传，请保持 `forIstoreOS/` 下的目录结构不变，不要把这些文件再套一层子目录。

## 8. 重要提醒

1. **不要每帧重发 `LCD_ADD`**，否则屏幕固件可能卡死，只能物理断电恢复。
2. **不要在时钟里加时区偏移**：路由器时区已是 `CST-8`。
3. **屏幕卡死时 USB 软复位无效**，必须物理拔插。
4. 网速页底部显示的是 **WAN 口 IP**；`100.64.0.0/10` 段会标 `NAT`，不代表真实公网 IP。
5. **开机自启默认关闭**，需要时执行 `/etc/init.d/msu2d enable`。
